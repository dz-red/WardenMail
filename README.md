# WardenMail
Внутрисерверная почта для Minecraft (Paper 1.21). Плагин-координатор: ведёт учёт (трек-номера, статусы, содержимое), а посылки физически возят игроки-курьеры.

## Возможности
- Почтовые отделения (хабы) с координатами
- Посылки: трек-номера, статусы (принята → прибыла → выдана), снапшот содержимого
- Роли курьер / ассистент (своя система прав в SQLite)
- Оффлайн-уведомления получателю

## Хранилище
SQLite (встроенная, без внешних БД).

## Сборка
`mvn clean package` (JDK 21).

## Стек
`Java 21` · `Paper API` · `SQLite` · `Maven`
